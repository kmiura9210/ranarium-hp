# 株式会社RANARIUM コーポレートサイト

Astro + Tailwind CSS v4 で構築したコーポレートサイトです。Cloudflare Pages にデプロイします。

## 開発

```sh
npm install
npm run dev
```

## ビルド

```sh
npm run build
```

## ページ構成

- `/` — トップ
- `/services` — サービス
- `/about` — 会社概要
- `/news` — お知らせ
- `/contact` — お問い合わせ

## Cloudflare Pages デプロイ設定

- ビルドコマンド: `npm run build`
- 出力ディレクトリ: `dist`
